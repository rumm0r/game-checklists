# 🎮 Game Checklists

> 🚧 **Work in progress!** This is a hobby project that grows as I play. Expect new features, the odd rough edge, and more games over time.

Hi! 👋 This is my little collection of checklists for the games I'm playing, so I never miss a chest, a steal or a side quest again.

**Play along at [rumgames.pages.dev](https://rumgames.pages.dev)**

## What's here so far

### Octopath Traveler II

- 🗝️ **Every steal and chest**, zone by zone, plus the hidden items you find by talking to people
- 📜 **All 67 side stories**: where they start, what unlocks them, and every step
- 🔍 **Who to Scrutinize**: the townspeople with hidden items, clues and better shop stock
- 🧭 **My progress**: set your chapters and see only what you can reach right now
- 💾 **Fill in from your save**: pick your save file and it ticks off what you've already done (the file never leaves your browser)
- ☁️ **Sign in with Discord** to keep your ticks on every device, or just use it without an account

## Coming up

- More games once I pick my next one
- Smaller polish and fixes as I find them

Got an idea or spotted something wrong? Open an issue. I'd love to hear it!

## For the curious

It's just plain HTML pages, no build step. Every push to `main` goes live on Cloudflare Pages automatically.

```
index.html                    home page listing every game
octopath-traveler-2/
  index.html                  the Octopath Traveler II checklist
```

Ticks save in your browser, separately for each game. If you sign in, they also sync to your account.
